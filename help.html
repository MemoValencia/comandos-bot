🎨 7TV
ComandoDescripción
_configurar [si/no]Con si añade o con no elimina los emotes definidos como { name, url } en CONFIGURED_EMOTE_LINKS. El guion bajo de name es una base: se sustituye automáticamente por el activador actual del canal. Por ejemplo, { name: '_musica', url: '...' } se configura como !musica si el activador del canal es !.
_agregar <url_emote_7tv>Añade un emote al set del canal.
_quitar <nombre_emote>Elimina un emote del set del canal.
_renombrar <nombre_actual> [nombre_nuevo]Renombra un emote o lo restaura al nombre original si no se da un nombre nuevo.
_7tv <acción>Gestiona acciones avanzadas del set de 7TV.
_robar [@canal] [emote]Roba un emote de otro set de 7TV y lo añade al tuyo.
_permitirmods [si/no]Permite o deniega a los mods usar 7TV.
_editor [usuario]Añade o quita editores autorizados en 7TV.
